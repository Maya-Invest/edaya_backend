# Optional subject enrollment V1

Participation is one current selection per class placement and class subject: Annual or selected academic periods. Compulsory admission remains automatic. Staff select optional choices; updates take effect at confirmation, with future periods beginning at their configured start. Unchanged period activations survive edits. Calendar hooks refresh coverage within placement/year bounds. Completion is date-driven.

Withdrawal checks dependencies inside the shared school academic-state lock. It physically deletes an unused enrollment. Linked subject attendance, marks, saved attendance drafts, frozen student rosters or published report sections instead cause a tombstone with deletedAt/deletedBy. Dependencies are checked across the offering/year, independently of selected periods. Daily attendance and other subjects are excluded. Saved academic work never cascades. Tombstones are internal, excluded from selection/eligibility and never automatically purged. Re-enrollment creates a new ID and activation. A partial unique index enforces one nondeleted row per placement/offering.

The canonical mutation accepts desired annual, period IDs or empty selections in atomic batches with scoped authorization, expected participation revisions and replay protection. Successful deletion replay uses the command journal, without loading a deleted enrollment. Public entity writes cannot bypass reconciliation or forge automatic participation.

Attendance retains saved entries/frozen rosters. Grading combines current eligibility with saved marks; existing marks remain editable/submittable, but do not authorize unrelated new marks. Published marks retain their locks. Draft marks can be deleted; submitted marks require approved exemption corrections. Reports retain contributing saved marks independently of selection and avoid empty weighted withdrawn subjects. Historical access uses saved records/snapshots; exact historical rosters without evidence are unavailable. Upcoming timetable/homework/teaching notifications use current selections; saved-result notification publication rules remain.

The staff Enrollments tab separates Class history and Optional Subjects. A shared Annual/period popup supports enroll/update/withdraw and explicit replacement of mixed bulk choices. No dates, reasons, interval correction, enrollment history or restore UI is exposed. Mobile has read-only child-specific selections and authoritative teacher rosters.

Qualify backend and generated TypeScript/Dart clients together on a separate freshly initialized database. Do not run this fresh-schema migration over existing legacy interval data or reset the local database. No implicit interval conversion/backfill is provided. Tests cover both deletion paths, retained work, replay, activation, period overlap, concurrency, permissions and transfers.
